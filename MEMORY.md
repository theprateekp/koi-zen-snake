# Memory

- The project is a React 19 + Vite web game at `/home/ubuntu/koi-zen-snake`.
- Babylon.js is installed from `@babylonjs/core`.
- The scene intentionally uses a 3D orthographic top-down camera so the game reads as a 2D grid while preserving garden depth and ripple presentation.
- Runtime images are bundled in `client/public/assets/` and documented in `ASSETS.md`.
- The public source and README contain no author or contributor attribution.
